# 路由与前端权限边界

路由是页面入口和参数边界。路由模块集中维护路径、组件、元信息和菜单关联；页面通过路由参数决定展示范围，不自行修改全局路由配置。

## 前端权限

前端可基于权限数据控制菜单、路由可见性和按钮呈现，以改善体验：

```ts
const canEdit = computed(() => permissions.value.includes('order:edit'))
```

这不是安全授权。任何真实数据访问和写操作必须由服务端再次校验。

## 规则

- 使用项目已有的 `router/modules/` 与路由元信息约定。
- 详情页路径、参数编码与返回行为遵循当前项目标准。
- 守卫处理登录态、必要初始化和无权限跳转；不在守卫中写业务页面逻辑。
- 菜单、路由和按钮权限字段应以项目实际权限契约为准，未确认时不可编造。
