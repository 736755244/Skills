# 前端基础设施与测试模式

前端基础设施包括 HTTP 客户端、Mock、运行时配置、存储封装、错误归一化和测试替身。它们服务于业务模块，不应反向包含页面规则。

## 测试分层

| 层级 | 关注点 | 建议工具 |
|---|---|---|
| 纯函数测试 | formatter、枚举、校验、映射 | Vitest |
| composable / 组件测试 | props、emit、loading、错误态 | Vitest + Vue Test Utils |
| 浏览器回归 | 路由、弹窗、表格、真实交互 | Playwright |

## 验证规则

- DTO 到展示模型的映射必须有代表性测试，特别是空值、未知枚举和日期金额格式。
- 保存、删除等写操作测试重复点击和失败反馈。
- 页面视觉和交互验证不能仅由类型检查替代。
- 需要可复跑 UI 回归时使用 `ui-verify-playwright`，遵循项目已有验证约定。
